# 🍕 Pibo - AR Pizza Ordering

یک وب‌سایت مدرن فروشگاه پیتزا با قابلیت واقعیت افزوده (AR) برای مشاهده سه‌بعدی محصولات قبل از خرید.

## ✨ ویژگی‌ها

- 🥽 **واقعیت افزوده (AR)**: مشاهده پیتزا در فضای واقعی با فایل‌های GLB و USDZ
- 📱 **سازگاری کامل با iPhone**: پشتیبانی از AR Quick Look در iOS
- 🤖 **سازگاری با Android**: پشتیبانی از Google Scene Viewer
- 🛒 **سبد خرید**: مدیریت سفارشات با ذخیره‌سازی محلی
- 📋 **سیستم سفارش‌گیری**: ثبت سفارش با اطلاعات مشتری
- 🔐 **پنل مدیریت**: مدیریت محصولات، دسته‌بندی‌ها، سفارشات و تنظیمات
- 📊 **داشبورد آمار**: نمایش آمار فروش و سفارشات
- 🎨 **طراحی مدرن**: رنگ‌های نارنجی و سفید با انیمیشن‌های اسکرول
- 📱 **ریسپانسیو**: سازگار با موبایل، تبلت و دسکتاپ

## 🚀 راه‌اندازی

### ۱. GitHub Pages
1. این مخزن را Fork کنید
2. به Settings > Pages بروید
3. Source را روی Branch: main و Folder: / (root) تنظیم کنید
4. سایت شما در چند دقیقه فعال می‌شود

### ۲. Firebase
- پروژه Firebase قبلاً تنظیم شده است
- داده‌ها در Realtime Database ذخیره می‌شوند

### ۳. AR Models
1. مدل ۳D خود را در [Luma AI](https://lumalabs.ai/) بسازید
2. خروجی GLB و USDZ بگیرید
3. فایل‌ها را در `assets/models/` آپلود کنید
4. مسیر فایل‌ها را در پنل ادمین > محصولات وارد کنید
